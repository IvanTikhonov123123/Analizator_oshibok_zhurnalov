# Анализатор журналов ошибок (Кейс №10) — Версия 0.2 (День 2–3)

## Что реализовано на текущем этапе:
1. **Графический интерфейс (День 2):** окно на базе `Tkinter` с кнопкой загрузки файла, панелью фильтрации, областью просмотра с горизонтальной/вертикальной прокруткой и строкой статистики.
2. **Загрузка логов (День 3):** открытие `.log` и `.txt` файлов с поддержкой кодировок UTF-8 и Windows-1251.
3. **Фильтрация по уровню важности (День 3):** поиск записей `ERROR`, `WARNING`, `INFO` с помощью регулярных выражений (`re`) и цветовая подсветка строк.
4. **Поиск по тексту и времени (День 3):** мгновенный поиск по подстроке в сочетании с выбранным фильтром уровня.

## Как запустить:
1. Убедитесь, что установлен Python 3.8+.
2. Запустите файл `main.py` командой `python main.py`.
3. Нажмите «Открыть файл» и выберите тестовый файл `sample_app.log`.

## План на День 4 (подготовка к релизу 1.0):
- Добавить экспорт отфильтрованных ошибок в отдельный отчёт (`.txt` или `.csv`).
- Добавить фильтр по диапазону времени (например, `08:20` — `08:35`).
- Расширить обработку нестандартных ситуаций (пустые файлы, слишком большие файлы).
